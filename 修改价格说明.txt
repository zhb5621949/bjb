GitHub 在线智能算价器 · 老板改价说明

一、修改价格
1. 登录 GitHub，打开智能算价器仓库。
2. 打开 data 文件夹，再打开 pricing.json。
3. 点击右上角铅笔图标（Edit this file）。
4. 修改对应项目的数字：
   - products：全部具体品类
   - category：所属大类（cookbook 菜谱、menu 菜单、other 其他）
   - rate：该品类每平方米单价
   - minimum：该品类默认最低价
   - processFees：各项工艺加价
   - styleFeeDefault：默认每款费用
   - 产品规格、材料和工艺说明集中在 product-data.js；日常只改价格时不用动这个文件
5. 把最上面的 version 数字加 1。
6. 修改 updatedAt，例如：2026-07-31T10:30:00+08:00。
7. 点击 Commit changes，再确认一次 Commit changes。

二、客服端更新
- GitHub 完成发布后，客服端每15秒自动检查价格。
- 发现新价格会提示“价格已自动更新到 V×”。
- 也可以点击页面右上角“刷新价格”立即检查。
- 客服不需要重新安装或重新接收软件。

三、第一次发布
1. 在 GitHub 创建一个公开仓库，建议命名：photo-pricing-calculator。
2. 上传本文件夹内的全部文件，必须保留 .github 文件夹。
3. 打开仓库 Settings → Pages。
4. 在 Build and deployment 的 Source 选择 Deploy from a branch。
5. 分支选择 main，文件夹选择 / (root)，然后保存。
6. Pages 页面会显示客服访问网址，把该网址发给客服。

四、安装到电脑
- 客服使用 Chrome 或 Edge 打开网址。
- 点击右上角“安装到桌面”。
- 如果没有出现安装按钮，可从浏览器右上角菜单选择“安装此应用”。
- 安装后桌面和开始菜单都会出现“智能算价”。

五、注意事项
- 只能修改数字和中文内容，不要删除引号、逗号、大括号或中括号。
- 当前共 36 个细分产品：菜谱 9 个、菜单 12 个、其他 15 个。
- 如果 GitHub 检查失败，客服端会继续使用上一次成功读取的价格。
- 本系统不保存客户资料和成本价。
