# 写真广告智能算价器

这是给客服使用的在线算价工具。已融合《产品种类和规格.xlsx》中的 36 个细分产品、常用规格、材料和生产工艺。客服先从“菜谱、菜单、其他”三大类中选择具体品类，再点击常用规格或输入定制尺寸，填写工艺、数量和款数，系统自动计算报价并执行最低价规则。

## 产品规格

- 菜谱类：9 个细分产品
- 菜单类：12 个细分产品
- 其他类：15 个细分产品（对应工作簿中的“宣传类”）
- 常用规格可一键带入长宽；选择“定制尺寸”后手动输入
- 每个产品下方显示外壳材料、内页/材料、外壳工艺和内页/材料工艺
- 材料和工艺直接按当前产品显示并选择；已移除通用的印色、覆膜、裁切、其他和参样工艺
- 菜谱类必须输入内页数量；该数量会显示在算价结果和复制报价中
- “另加内页”按单页面积 × 内页数量 × 菜谱本数量计价，默认 38 元/㎡、最低 40 元，可在价格配置中修改

## 老板修改价格

只需编辑 [`data/pricing.json`](data/pricing.json) 并提交。发布完成后，客服端会自动读取新价格。产品专用选项目前不加价；需要为某个选项加价时，可在 `optionFees` 中填写对应的每平方米加价。

## 第一次开启网页

在仓库的 **Settings → Pages** 中，把 **Source** 设置为 **Deploy from a branch**，分支选择 **main / (root)** 并保存。发布完成后，Pages 页面就会给出访问网址。

## 客服安装

客服使用 Chrome 或 Edge 打开在线网址，点击页面右上角的“安装到桌面”。以后可像普通软件一样从桌面打开。

详细操作请查看仓库中的《修改价格说明.txt》。
