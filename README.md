# 写真广告智能算价器

这是给客服使用的在线算价工具。输入材质、尺寸、工艺、数量和款数后，自动计算报价并执行最低价规则。

## 老板修改价格

只需编辑 [`data/pricing.json`](data/pricing.json) 并提交。发布完成后，客服端会自动读取新价格。

## 第一次开启网页

在仓库的 **Settings → Pages** 中，把 **Source** 设置为 **GitHub Actions**。随后等待 Actions 显示绿色对勾，Pages 页面就会给出访问网址。

## 客服安装

客服使用 Chrome 或 Edge 打开在线网址，点击页面右上角的“安装到桌面”。以后可像普通软件一样从桌面打开。

详细操作请查看仓库中的《修改价格说明.txt》。
